# HEMIS

Мобильное приложение студенческого кабинета в стиле HEMIS: React + Vite + Tailwind.
Работает как PWA: его можно установить на iPhone и Android с сайта на GitHub Pages.
Данные лежат в `src/data.ts`, сервера и настоящего входа нет.

Сайт: https://humoyunmirzo007.github.io/hemis-final/

## Установка на телефон

- **iPhone:** открыть сайт в Safari → «Поделиться» → «На экран Домой».
- **Android:** открыть сайт в Chrome → меню ⋮ → «Установить приложение» (или «Добавить на гл. экран»).

## Разработка

1. `npm install`
2. `npm run dev` и открыть http://localhost:3000

Каждый push в `main` автоматически собирает и выкладывает сайт (`.github/workflows/deploy.yml`).
После изменений поднимайте `VERSION` в `public/sw.js`, чтобы у установленных приложений обновился кэш.

## Структура

- `src/data.ts` — данные: студент, семестры, оценки, расписание, экзамены, пропуски
- `src/ui.tsx` — общие элементы: шапка экрана, пустые состояния, загрузка, фильтры
- `src/tabs.tsx` — пять вкладок: Главная, Расписание, HEMIS AI, Предметы, Все
- `src/screens.tsx` — внутренние экраны: успеваемость, посещаемость, документы, платежи и другие
- `src/App.tsx` — рамка телефона на компьютере, навигация, боковое меню, вход
- `public/` — иконки, манифест PWA и service worker для офлайн-режима
